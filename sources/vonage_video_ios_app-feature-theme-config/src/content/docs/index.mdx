The Vonage Video iOS App (`vonage-video-ios-app`) is a Swift application built with Tuist. It controls which features are enabled and how the app looks through two JSON configuration files — **`VERA/Config/app-config.json`** for feature flags and **`VERA/Theme/semantics.json`** for theme tokens — each paired with a Python generator script that turns your edits into Swift source and asset catalogs. This Codespace has no Xcode or macOS, so this tutorial verifies your changes by inspecting generator output rather than building or running the app.

In this tutorial you will:

- Set up the shared backend server and generate the app's environment constants
- Understand how feature flags are structured in `app-config.json`
- Edit feature flags and regenerate the corresponding Swift configuration
- Understand how color, border radius, and typography tokens are structured in `semantics.json`
- Edit theme tokens and regenerate the corresponding color assets
- Confirm your changes by inspecting generator output and generated files
