---
title: Test and Validate
description: Send the SMS and copy its message UUID back to the learning path.
---

Reload the **SMS Message App**. The credential and SDK checks should now be green.

Keep the default message or enter a short test message, then select **Send SMS**. When the Messages API accepts the request, the page displays the message UUID returned by the API.

Copy the UUID from the **Completed exercise credentials** panel and paste it into the field with the same name in your learning path tab.

An accepted request does not guarantee handset delivery. You will follow the message through status callbacks in the next coding exercise.

After the learning path marks this exercise as complete, you may close this Codespace and return to the learning path.
