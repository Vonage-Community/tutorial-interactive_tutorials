---
title: Open the SMS App
description: Open the Codespace application running on port 3000.
---

The Simple Browser displays this exercise guide. The **SMS Message App** is a separate application running on port `3000`.

Open the `APPLICATION READY` URL printed in the initial terminal. If port `3000` appears in the **Ports** tab, you can also open its **Forwarded Address**.

The page shows your configuration and the implementation checks for this exercise. Keep it open and reload it after each code change so it uses the latest server logic.
