---
title: Find the Session
description: Use the live Session ID to locate the call in Session Inspector.
---

Select **Stop session**, then copy the **Session ID** shown in the monitor.

Open [Session Inspector](https://tools.vonage.com/video/inspector), sign in to the same Vonage account used during setup, and search for that Session ID.

Inspector is a post-call tool, and the session data may take approximately five minutes to appear. When it is available, compare the session participants, connections, stream, events, and quality metrics with the identifiers stored by your backend.

This review is not part of automatic exercise validation because Inspector requires an authenticated browser session and its data is not immediate.
