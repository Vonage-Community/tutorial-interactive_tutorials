# Review the Evidence

Return to the monitor. Select **Reset data**, then run **Sustained subscriber issue** once more.

The **Correlated evidence** section should show:

- `3` telemetry records,
- `2` platform quality samples,
- the subscriber connection ID,
- the affected stream ID.

The example platform samples represent bitrate, packet loss, and latency measurements that an investigation can compare in Session Inspector or retrieve through an appropriate Insights workflow. The exercise uses prepared data so completion does not depend on account access, data retention, or processing latency.

The report is now tied to a specific participant, stream, and time window.
