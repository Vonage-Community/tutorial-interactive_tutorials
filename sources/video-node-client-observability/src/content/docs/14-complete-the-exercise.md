# Complete the Exercise

At the top of the monitor, confirm that all four backend checks are green:

- Normalize telemetry with session context.
- Summarize publisher and subscriber samples.
- Detect a sustained quality issue.
- Correlate a support report with platform data.

The monitor now displays a **Completion credential**. Copy that value and paste it into the **Completed exercise credentials** field in the Learning Center.

{% aside type="tip" %}
The completion credential appears only when the four functions produce the expected results. It does not depend on which sample scenario is currently stored in the monitor.
{% /aside %}

Your backend can now preserve client telemetry, summarize sessions, limit noisy alerts, and prepare evidence for an investigation.
