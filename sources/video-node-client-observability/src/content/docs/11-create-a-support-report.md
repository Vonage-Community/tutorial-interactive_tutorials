---
title: Create a Support Report
description: Match the live subscriber records to a support time window.
---

Select **Create support report**.

The prepared application creates a report for the subscriber and the time covered by the stored records. Your `correlateSupportCase()` function should return:

- The subscriber telemetry inside that time window.
- The subscriber connection ID.
- The published stream ID.

These identifiers connect an application user and a reported time with the Video API objects shown in Inspector.
