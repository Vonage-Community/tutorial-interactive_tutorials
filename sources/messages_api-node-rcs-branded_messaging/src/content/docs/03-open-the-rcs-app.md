---
title: Open the RCS App
description: Open the Codespace application running on port 3000.
---

The Simple Browser displays this exercise guide. The RCS message app is a separate application running on port `3000`.

Open the **Ports** tab in the bottom panel and select the forwarded address for port `3000`. You can also click the `APPLICATION READY` URL printed in the initial terminal.

The page shows whether your RCS credentials are present and displays a short form for sending the message. If port `3000` is private, set it to **Public** so Vonage can reach the status webhook.

Keep this browser tab open. After each code change, reload the RCS app so it uses the latest server logic.
