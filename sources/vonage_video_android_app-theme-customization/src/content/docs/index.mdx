The Vonage Video Android App (`vonage-video-android-app`) is a Kotlin application built with Gradle. It controls how the app looks through a single JSON configuration file — **`config/theme.json`** — paired with a custom Gradle plugin that turns your edits into generated Compose theme resources. This tutorial's Codespace can't run Android Studio or an emulator, so all editing and building happens in a clone of the repo on your own machine; the Codespace only runs the shared backend server the app connects to.

In this tutorial you will:

- Clone `vonage-video-android-app` locally and run it in Android Studio against the shared backend
- Understand how color, border radius, and typography tokens are structured in `theme.json`
- Edit theme tokens and regenerate the corresponding Compose theme resources
- Rebuild and confirm your changes in the Android emulator
