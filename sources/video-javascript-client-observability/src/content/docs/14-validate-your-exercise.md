---
title: Validate Your Exercise
description: Copy the application URL back to the Learning Path.
---

You have completed the frontend exercise for the Client Observability learning path. The application now checks readiness before a call and continues monitoring after the user joins.

Copy your Application URL and paste it into the **Completed exercise credentials** field in your Learning Path. This validates the exercise and contributes to the completion certificate when the Learning Path is finished.

You can find the Application URL under port `3000` in the **Ports** tab. After you copy it, you may close the exercise and return to your Learning Path.
