# Complete the Exercise

At the top of the application, confirm that all nine checks are complete:

- Enable and collect publisher statistics.
- Collect subscriber statistics.
- Listen for quality and network changes.
- Identify local and remote degradation.
- Run connectivity before the quality test.
- Return `Pass`, `Warn`, and `Fail` decisions.
- Apply the recommended publish settings.
- Complete a pre-call test in a separate routed session.
- Collect live Publisher and Subscriber statistics from the communication session.

The application now displays a **Learning Center validation URL**. It is the forwarded address for this Codespace application on port `3000`.

Copy the complete URL and paste it into the **Completed exercise credentials** field in the Learning Center. The URL appears only after the implementation checks, pre-call test, and live Publisher and Subscriber telemetry are complete.
