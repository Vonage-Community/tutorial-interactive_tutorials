# Open the Client Observability File

Open:

```text
project/public/client-observability.js
```

This file contains five functions. They enable sender-side statistics, poll Publisher and Subscriber statistics, listen for quality changes, and read the Subscriber degradation source.

Start with the Publisher options used when the application joins the live session.

For each function, keep its declaration and braces. Remove the `TODO` and the complete placeholder body before pasting the code from the matching step. After saving, wait for the server to restart and reload the Client Observability application.
