# Check the Starter Project

The Codespace contains a working application in `project/`. Its backend creates Video API sessions and tokens, while the browser provides the waiting room and live quality monitor.

```text
project/
  public/
    app.js
    client-observability.js
    index.html
    pre-call.js
    styles.css
  src/
    exercise-validation.js
    exercise-state.js
    video-routes.js
  .env.example
  package.json
  server.js
  setup-credentials.js
```

You will edit only:

- `project/public/client-observability.js`
- `project/public/pre-call.js`

Each `TODO` marks one function used by the application and by the implementation checks. The application also records whether you complete a real pre-call test and collect Publisher and Subscriber statistics from the same live session.
