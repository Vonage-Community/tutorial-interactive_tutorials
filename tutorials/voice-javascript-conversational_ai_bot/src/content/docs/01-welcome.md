# Build a Conversational AI Voice Bot

This is a shared Codespace for the Voice Automation learning path. You will return to this same guide from three courses: first to build a basic AI voice bot, then to add conversation memory, and finally to transfer the caller to a human agent.

The Codespace contains a starter Node.js project in `project/`. Each part adds a small piece of the Voice API call flow, so keep the Codespace open when the guide asks you to return to the learning path.

You need:

- a Vonage account with a Voice-capable virtual number;
- a Vonage Voice Application linked to that number;
- an OpenAI API key;
- a phone you can use to call your Vonage number.

Start with the first part below. When you finish it, the guide will tell you when to switch back to the learning path.
