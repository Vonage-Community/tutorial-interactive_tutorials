# Verify the Server

The Codespace starts the Express server automatically. In the bottom panel, open the **Ports** tab and find port `3000`.

Open its **Forwarded Address**. If the server is running correctly, the page displays:

```text
I'm listening!
```

Leave the server running for the next steps. If it restarts after you save `index.js`, reload the browser tab that shows the application.
