The Vonage Video iOS App (`vonage-video-ios-app`) is a Swift application built with Tuist. It controls which features are enabled through a single JSON configuration file — **`VERA/Config/app-config.json`** — paired with a Python generator script that turns your edits into Swift source. This tutorial's Codespace has no Xcode or macOS, so all editing and building happens in a clone of the repo on your own Mac; the Codespace only runs the shared backend server the app connects to.

In this tutorial you will:

- Clone `vonage-video-ios-app` locally and run it in Xcode against the shared backend
- Understand how feature flags are structured in `app-config.json`
- Edit feature flags and regenerate the corresponding Swift configuration
- Rebuild and confirm your changes in the iOS Simulator
