# Dial da Vinci workshop

In this workshop, we will create an AI Voice Agent that can answer phone calls and act as Leonardo da Vinci. After that you'll be able to create your own Agent of whoever you'd like to speak to.

The <a href="https://flueframework.com" target="_blank">Flue Framework</a> will be used to create the AI Agent and server.

The call answering functionality and communication with the AI will be handled by the <a href="https://developer.vonage.com/en/voice/voice-api/overview" target="_blank">Vonage Voice API</a>
