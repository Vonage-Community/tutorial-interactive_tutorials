The Vonage Video Android App (`vonage-video-android-app`) is a Kotlin application built with Gradle. It controls which features are enabled through a single JSON configuration file — **`config/app-config.json`** — paired with a custom Gradle plugin that turns your edits into Kotlin constants and build configuration. This tutorial's Codespace can't run Android Studio or an emulator, so all editing and building happens in a clone of the repo on your own machine; the Codespace only runs the shared backend server the app connects to.

In this tutorial you will:

- Clone `vonage-video-android-app` locally and run it in Android Studio against the shared backend
- Understand how feature flags are structured in `app-config.json`
- Edit feature flags and regenerate the corresponding Kotlin configuration
- Rebuild and confirm your changes in the Android emulator
