The Vonage Video iOS App (`vonage-video-ios-app`) is a Swift application built with Tuist. It controls how the app looks through a single JSON configuration file — **`VERA/Theme/semantics.json`** — paired with a Python generator script that turns your edits into a color asset catalog. This tutorial's Codespace has no Xcode or macOS, so all editing and building happens in a clone of the repo on your own Mac; the Codespace only runs the shared backend server the app connects to.

In this tutorial you will:

- Clone `vonage-video-ios-app` locally and run it in Xcode against the shared backend
- Understand how color and typography tokens are structured in `semantics.json`
- Edit color and typography tokens and regenerate the corresponding color assets
- Rebuild and confirm your changes in the iOS Simulator
