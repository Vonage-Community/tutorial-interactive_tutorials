# Open the Application

The **Simple Browser** displays this exercise guide. The **Client Observability** application is a separate application running on port **3000**.

To open the application:

1. Select the **Ports** tab in the bottom panel, next to **Terminal**.
2. Find port **3000**.
3. Select the generated **Forwarded Address** for port 3000.

If port 3000 is not listed, open a terminal and run:

```sh
cd project && npm start
```

Leave the terminal running, return to **Ports**, and open the forwarded address.

The nine checks are initially incomplete. The server restarts when you save either exercise file. Reload the application in its browser tab after each restart to use the latest browser code and refresh the checks.
