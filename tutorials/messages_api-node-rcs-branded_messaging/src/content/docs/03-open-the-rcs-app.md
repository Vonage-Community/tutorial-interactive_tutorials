---
title: Open the RCS App
description: Open the Codespace application running on port 3000.
---

The Simple Browser displays this exercise guide. The RCS message app is a separate application running on port `3000`.

Click the `APPLICATION READY` URL printed in the initial terminal. If port `3000` appears in the **Ports** tab, you can also open its **Forwarded Address** from there.

The page shows whether your RCS credentials are present and displays a short form for sending the message. Port `3000` is made public automatically so Vonage can reach the status webhook.

Keep this browser tab open. After each code change, reload the RCS app so it uses the latest server logic.
