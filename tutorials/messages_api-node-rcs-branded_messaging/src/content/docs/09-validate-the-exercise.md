---
title: Validate the Exercise
description: Copy the validation URL back to the learning path.
---

The RCS app displays a **Learning Path validation URL** after the implementation checks pass, the Messages API accepts the message, and the status webhook receives an event for that message.

Copy the complete URL and paste it into the **Completed exercise credentials** field in your learning path tab.

The URL appears only after the current Codespace has sent an RCS message and received a matching status event.

You may now close this tab and return to your learning path.
