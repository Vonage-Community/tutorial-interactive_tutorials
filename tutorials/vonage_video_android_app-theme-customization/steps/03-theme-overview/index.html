Theme Configuration Overview

The Android app's visual theme lives in a single JSON file in your local clone: config/theme.json. This is the file you'll edit to customize colors, corner rounding, and typography without touching any Kotlin or Compose source code.

How It's Structured

Section titled “How It&#39;s Structured”

theme.json nests every token under themes.vonage, split into three groups: colors, borderRadius, and typography:

  • colors.light / colors.dark — Separate color palettes for each mode. Both modes use the same set of semantic token keys, including on-* pairs (e.g. on-primary) for text/icon color placed on top of that token.
  • borderRadius — Six named tokens controlling the corner rounding of buttons, cards, and dialogs.
  • typography — desktop and mobile type scales. Both scales use the same named tokens, just with different point sizes.
