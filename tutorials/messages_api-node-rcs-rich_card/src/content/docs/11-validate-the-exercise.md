---
title: Validate the Exercise
description: Copy the validation URL back into the learning path.
---

You have completed the RCS rich card exercise. The app now sends a rich card with a public PNG media URL, receives status events, and records the suggested reply selected by the recipient.

The app displays the **Learning Path validation URL** after it has received both:

- a status event for the rich card you sent;
- an inbound reply event from one of the suggested replies.

Copy the complete URL and paste it into the **Completed exercise credentials** field in your learning path.

You may now close this tab and return to your learning path.
