---
title: Open the Rich Card App
description: Open the application running on port 3000.
---

The Simple Browser displays this guide. The RCS Rich Card App is a separate application running on port `3000`.

Open the **Ports** tab in the bottom panel, find port `3000`, and open its **Forwarded Address**. You can also click the application URL printed by the setup script.

The app shows your configured sender, webhook URLs, implementation checks, a preview of the Vonage logo, and a button for sending the rich card.

Keep this tab open while you complete the code steps.
