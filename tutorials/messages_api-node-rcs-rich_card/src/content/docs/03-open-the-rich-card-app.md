---
title: Open the Rich Card App
description: Open the application running on port 3000.
---

The Simple Browser displays this guide. The RCS Rich Card App is a separate application running on port `3000`.

Click the `APPLICATION READY` URL printed in the initial terminal. If port `3000` appears in the **Ports** tab, you can also open its **Forwarded Address** from there.

The app shows your configured sender, webhook URLs, implementation checks, a preview of the Vonage logo, and a button for sending the rich card. Port `3000` is made public automatically so Vonage can reach the webhook URLs.

Keep this tab open while you complete the code steps.
