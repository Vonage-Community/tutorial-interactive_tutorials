---
title: Validate the Exercise
description: Copy the correlated message UUID back to the learning path.
---

The monitor displays **Completed exercise credentials** after the current Codespace sends an SMS and receives a status callback with the same message UUID.

Copy the UUID from that panel and paste it into the **Completed exercise credentials** field in your learning path tab.

After the learning path marks this exercise as complete, you may close this Codespace and return to the learning path.
